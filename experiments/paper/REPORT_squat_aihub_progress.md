# 스쿼트 무릎각 보정 — 결과

## 실험 설정
- 목표: `residual = GT각 − MediaPipe각` 학습 → 보정각 = MediaPipe각 + 예측잔차
- 입력 특징: `enhanced_safe` 39개 (MediaPipe world 무릎각 + 하체 좌표·속도·가시성·분절안정성·화각)
- 회귀 모델: ExtraTrees (n_estimators=500, max_depth=15)
- 검증: 피험자단위 Leave-One-Subject-Out (LOSO)
- 지표: 전체(mean) 및 깊은굴곡(<110°) MAE, LOSO 피험자평균
