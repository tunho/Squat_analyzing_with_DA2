## 부록 — 잔차 vs 직접 ablation (ExtraTrees, 16칸)
- 잔차 우월 3칸 / 직접 우월 5칸 / 비슷 8칸 → 트리는 평균 동등. **단 잔차가 저오차 도메인 파국 회피**(fit_nlf: 잔차+27 vs 직접−9.5).
- 결론: 잔차 = 더 견고·해석가능한 기본값 (정확도 hook 아님, 안전성 hook).

## 핵심 메시지
1. **추정기 비종속**: 4추정기 전부 보정 작동(+8~83% in-domain, +43~70% pooled).
2. **임상 enablement**: 깊이판단 99.6%+, 정확한 추정기(NLF)면 깊이오차 <5° 임상-grade.
3. **견고성**: 7보정기 중 ExtraTrees만 전 조건 파국 0 (경쟁자 −90~−384%).
4. **일반화 경계 정직**: 미관측 subject 강건, 미관측 도메인 위험(추정기 의존), few-shot 복구.
