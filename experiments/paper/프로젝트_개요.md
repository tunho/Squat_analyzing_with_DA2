# 프로젝트 개요 — 방학 동안 한 일

> 한 줄: **카메라 영상으로 사람의 무릎 각도를 추정하고, 그 추정값의 오차를 학습으로 보정하는 연구.**

---

## 1. 무슨 문제인가
스쿼트 같은 동작에서 무릎이 얼마나 굽었는지(무릎 각도)를 알고 싶다.
- **정답(GT)**: 모션캡처 장비로 잰 실제 3D 관절 → 진짜 무릎 각도.
- **현실**: 장비 없이 그냥 카메라 영상으로 추정하면 오차가 생긴다.

핵심 관찰: 이 오차는 **무작위가 아니라 체계적(일정한 경향)** 이다 → 그렇다면 **학습으로 고칠 수 있다.**

## 2. 전체 흐름 (파이프라인)
```
영상  →  [추정기]  →  무릎각 시계열(프레임별)  →  [보정기]  →  보정된 무릎각
                          │                          ↑
                          └── 정답(GT)과 비교해 "오차(잔차)"를 학습 ──┘
```
1. **추정기**가 영상에서 프레임마다 3D 관절 → 무릎 각도 시계열을 뽑는다.
2. **보정기**가 `오차 = 정답 − 추정값`(잔차)을 학습한다.
3. 새 영상엔 `보정값 = 추정값 + 예측한 오차`로 고친다.

## 3. 실험 자산 (무엇을 비교했나)
- **추정기 4종** (무릎을 추정하는 프로그램): MediaPipe(가볍고 빠름), NLF(정확), RTMW3D, MotionBERT.
- **도메인(데이터) 4종** (촬영 환경): 재활 클리닉(REHAB), 피트니스(FiT3D), 모션캡처 랩(SUMe), 대규모(AIHub).
- **보정기 여러 종**: 고전 평활(SavGol·Kalman), 학습형(MLP·**ExtraTrees**=주력), 최신 딥러닝(SmoothNet·TCN·Diffusion·ExcelFormer·**TabM**).

## 4. 실험 방식 (어떻게 테스트했나)
| 방식 | 설명 | 묻는 것 |
|---|---|---|
| **① 도메인 내 (in-domain)** | 같은 데이터 안에서 사람만 나눠 학습/테스트 (LOSO) | 안 본 사람에게도 되나? |
| **② 다 합쳐 (pooled)** | 4개 도메인 다 합쳐 학습, 안 본 사람 테스트 | 하나의 모델로 두루 되나? |
| **③ 도메인 간 (cross-domain)** | 한 도메인 통째로 빼고 그 도메인으로 테스트 (LODO) | 완전히 새 환경에서도 되나? |
| **④ 소량 보정 (few-shot)** | 새 환경 사람 1~3명만 추가로 보여주고 테스트 | 조금만 맞춰주면 회복되나? |

## 5. 핵심 발견 (요약)
- **① 도메인 내·② 합쳐서**: 잘 된다 — 오차가 크게 줄고, 임상 기준(±5°)도 개선.
- **③ 도메인 간**: 실패한다 — 배운 적 없는 환경에선 오히려 나빠지기도(backfire). 어떤 보정기도 마찬가지.
- **④ 소량 보정**: 새 환경 사람 1~3명만 추가하면 다시 좋아진다.
- **보정기 비교**: 단순 트리(ExtraTrees)가 최신 딥러닝만큼, 특히 **데이터가 적을 땐 더 견고**하다.

## 6. 방학 동안 실제로 한 일
- 추정기 4종 × 도메인 4종으로 **무릎각 시계열 데이터 추출**.
- 보정기 여러 종을 **동일 조건으로 비교** (고전~2025 최신 딥러닝까지).
- ①②③④ 네 가지 실험을 **모든 추정기·도메인에 걸쳐** 수행.
- **임상 유용성**(각도 오차·깊이 개선) 분석 + 통계 검증.
- **실시간 보정** 가능성(폰용 MediaPipe + 경량 보정) 검토.
- **재현성** 정비(시드 고정·환경 기록).

## 7. 결론 한 줄
**같은/여러 환경 안에서는 markerless 무릎각을 학습 보정으로 임상 수준까지 개선할 수 있고, 완전히 새 환경은 소량 보정으로 해결된다. 이 결론은 트리부터 2025년 최신 딥러닝까지 일관된다.**
