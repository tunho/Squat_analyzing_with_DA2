## E. 논문 기여(novelty) 시도

논문 기여로 만들려 시도한 방법들과 결과. '시도한 방법'=무엇을 했는지, '결과'=핵심 수치.
| 시도한 방법 | 결과 |
|---|---|
| 언제 보정할지 자동 선택 | 예측력 거의 없음 (~우연) |
| 분포 겹침으로 보정 가능성 예측 | 상관 +0.2 |
| 도메인 간 오차지도 전이 | 도메인 내 0.91 / 간 0.44 |
| 여러 추정기 결합(stacking) | 도메인 내 +14 / 간 실패 |
| 추론 시 부드럽게 만들기(TTA) | 9.7→24.9° (악화) |
| 도메인별 1차 보정(offset+scale) | 악화만 막고 회복은 못 함 |
