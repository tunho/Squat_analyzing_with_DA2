# PART B — 수치 (정확히 사용)

## 데이터셋 (표1)
AIHub 46명/8캠/14.3°/삼각측량 · SUMediPose 26명/6캠/12.6°/**Vicon** · REHAB24-6 9명/2캠/12.0°/3D joints · FiT3D 3명/4캠/20.3°/mocap. 합계 84명.

## 결과① In-domain LOSO (4셋, full / deep)
AIHub 14.31→7.97 **+44.3%**/deep+39.3 · SUMediPose 12.65→7.26 **+42.6%**/deep+53.5 · REHAB 12.29→8.11 **+34.0%**/deep+61.9 · FiT3D 20.25→11.94 **+41.0%**/deep+62.1

## 방법 정당화
- Ablation(누적): 각도만 +9.1% → 하체좌표(+9피처) **+33.6%** → 분절안정성 +35.4 → 가시성 +37.2 → 전체(39) **+38.3%**
- 회귀기: Linear +13.6% ≪ HistGBM/RF +37.0 ≈ ExtraTrees/LightGBM +38.3 ≈ XGBoost +38.6 (트리 앙상블 동급, ExtraTrees 채택=무튜닝·결정성)

## 결과② 베이스라인 (pooled, 개선율)
제안 **+38.4%**(deep +43.5) · 선형회귀 +13.5%(deep+19.9) · 아핀 +2.1% · Savitzky–Golay ≈0% · 피험자별 캘리브 −26.7%. → 제안=선형의 2.8배, 모든 베이스라인·4셋 우위.

## 결과③ 통계
+38.4%, 95% CI [36.8, 39.9], Wilcoxon p=1.7×10⁻¹⁵, 84/84 개선.

## 핵심① 단일소스 전이 매트릭스 (full / deep %)

→ +29%부터 −19%(악화)까지. 다인자 도메인 시프트.

## 핵심② 다도메인 풀링 = 미지 피험자 (pooled LOSO)

## 핵심③ 미지 도메인 zero-shot (LODO, per-subj 개선 / 95% CI)
AIHub −11.4 [−14.0,−8.8] · SUMediPose +21.5 [+18.3,+24.7] · REHAB +2.5 [−4.8,+10.5] · FiT3D +25.2 [+16.4,+33.1] · **전체 +1.6 [−2.2,+5.7] (CI 0 포함=신뢰 불가)**. 단 deep은 3/4 양수(AIHub +28).

## 핵심④ few-shot 회복 (k=0→3, pooled %)
