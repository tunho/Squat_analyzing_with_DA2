# 상위 논문 계획서 — 현재 상태에서의 진로

작성: 2026-06-05 / 전제: 중급 논문(Topic C)·석사 논문 내용은 이미 확보됨.
이 문서는 **그 위(상위)로 가려면 무엇을 더해야 하는가**를 정직하게 설계한다.

---

## 0. 한 줄 요약

현재 자산만으로는 상위가 막힌다. 막는 건 **(1) 방법 신규성 부족, (2) 도메인 수 부족(4개), (3) 전이 실패 메커니즘 미규명** 세 가지다.
상위로 가는 가장 현실적·고가치 경로는 **"타깃 데이터 없이(zero-shot) 미지의 카메라/도메인에 일반화되는 보정"** 을 *통제실험으로 입증*하는 것이다. 부차로 **불확실성 인지(uncertainty-aware) 보정**이 방법 신규성을 보탠다.

---

## 1. 현재 위치 (자산과 한계)

### 가진 자산 (강점)
- 4개 독립 데이터셋·84명, **Vicon 골드 GT** 포함.
- **통제 가능한 시점(viewpoint) testbed**: SUMediPose 26명×6캠, AIHub ~46명×8캠 — *같은 사람·같은 동작, 카메라만 변함*. 상위 통제실험의 핵심 재료.
- 엄격한 평가 관행(LOSO, 베이스라인 4종, 부트스트랩 CI, Wilcoxon).
- 검증된 발견: 단일소스 전이 불안정(−18.6%~+28.9%), 다도메인 풀링이 해결(84/84).
- 추출 파이프라인(raw dump, 4셋 통합) — 추가 데이터 흡수 즉시 가능.

### 이미 기각한 길 (다시 파지 말 것)
- ❌ 카메라 거리/높이로 오차·전이실패 설명 → 측정 결과 r≈0, **기각**.
- ❌ 오차 부호가 전이 법칙 → FiT3D 반례로 **기각**.
- → 함의: "단순 기하 한 변수"로 미는 상위 스토리는 불가. 메커니즘은 **다인자**이며, 해법은 **데이터 기반 적응**이어야 한다.

### 상위를 막는 핵심 한계
1. **방법 신규성**: 트리 잔차보정은 기법적으로 평범. 상위 CV/ML은 신규 방법을 요구.
2. **도메인 수**: 4개로는 "일반화된다"를 주장 못 함. leave-one-*dataset*-out을 의미있게 하려면 8~10개 도메인 필요.
3. **메커니즘 미규명**: "왜 깨지나/언제 되나"를 예측 못 함. 상위는 이 예측가능성을 요구.

## 2. "상위"의 정의 — 어느 top을 노리나

현실적 타깃을 먼저 못박는다. 두 종류의 top은 요구가 다르다.

| 트랙 | 예시 venue | 핵심 요구 | 본 연구 적합도 |
|---|---|---|---|
| **A. 상위 응용/바이오메디컬 (현실적)** | IEEE J-BHI, IEEE TNSRE, IEEE TBME, Journal of Biomechanics (Q1) | 엄격 검증 + 임상적 가치 + 일부 방법 기여 | **높음** (강추) |
| B. 상위 CV/ML (도전적) | CVPR/ICCV/ECCV, TPAMI, IJCV | 강한 방법 신규성, SOTA 비교 | 낮음 (방법 재설계 필요) |

**권장: 트랙 A (Q1 응용지).** 우리의 강점(다중 GT·통제 testbed·임상 의미)이 그대로 가점이 되고, 방법 신규성 요구가 B보다 낮다. B는 별도 방법 연구가 선행돼야 하므로 후순위.

## 3. 후보 방향 (기여·필요데이터·방법·리스크)

### 방향 ① ★ Target-free / zero-shot cross-setup 보정 (추천 primary)
- **기여**: 미지의 카메라 배치·새 데이터셋에 **타깃 GT 없이** 일반화되는 보정. 중급 논문이 남긴 정확한 open question("다도메인은 되지만 타깃 도메인이 학습에 있어야 함 → 진짜 미지셋은?")의 해결.
- **왜 상위인가**: 현장 배포의 본질 문제(새 체육관/새 폰 카메라). leave-one-dataset-out에서 zero-shot이 단일소스 naive를 이기면 강력.
- **방법(신규성 원천)**: 기하 한 변수가 안 되므로 **데이터 기반 적응**:
  - (a) **Test-time adaptation**: GT 없이 자기지도 신호로 미지 도메인 적응 — 시간적 일관성(부드러움), 좌우 대칭, 분절 길이 불변, (다카메라 보유 시) 멀티뷰 일관성.
  - (b) **도메인-불변 표현**: 도메인 적대학습/정규화로 보정기를 도메인 무관하게.
  - (c) **도메인-조건 보정**: 회복 가능한 도메인 통계(시점 분포 요약 등)로 조건화 — 단, 단일 기하변수 금지(기각됨), *분포 수준* 특징 사용.
- **필요 데이터**: **도메인 수 확대가 필수**(섹션 5). 통제 testbed(SUMediPose/AIHub 멀티캠)로 viewpoint hold-out.
- **리스크**: zero-shot이 다도메인 풀링을 못 이길 수 있음 → 그땐 "few-shot(타깃 N프레임)로 회복" 으로 후퇴 가능(여전히 publishable).
- **소요(추정)**: 데이터 확보 1~2개월 + 방법·실험 2~3개월.

### 방향 ② 전이 실패 메커니즘의 *예측 모델* (추천 보조 — ①과 결합)
- **기여**: "언제 보정이 되고 안 되나"를 **측정 가능 요인으로 예측**. 통제실험으로 인과 분리.
- **방법**: SUMediPose 26명×6캠 = 사람·동작 고정, 카메라만 변하는 **자연 통제실험**. 카메라별 오차 ↔ (자기가림/foreshortening/동작면 대비 시점/평균 가시성) 다중회귀·부분상관. AIHub 8캠으로 점 수 확보. *단일 기하 아닌 다인자 모델*.
- **왜 상위 보탬**: ①의 zero-shot이 "왜 되는지"를 설명 → 논문 깊이↑. 단독으론 약하니 ①의 한 섹션으로.
- **필요 데이터**: 이미 보유(SUMediPose/AIHub 멀티캠). **추가 데이터 거의 불필요** → 저비용·저위험.
- **리스크**: 다인자라 깔끔한 단일 설명이 안 나올 수 있음(정직하게 "예측 가능하나 다인자"로).

### 방향 ③ 불확실성 인지(uncertainty-aware) 보정 (방법 신규성 보강)
- **기여**: 잔차 + **신뢰도(언제 MediaPipe를 믿을지)** 동시 출력. 임상에서 "이 프레임은 신뢰 불가" 경고 → 실용·신규성 둘 다.
- **방법**: 분위수 회귀/앙상블 분산/conformal prediction으로 per-frame 불확실성. 고불확실 프레임 거부 시 정확도-커버리지 곡선.
- **필요 데이터**: 기존으로 가능. **저비용**.
- **왜 보탬**: 트랙 A(임상지)에서 매우 선호. ①+③ 조합이 "robust + 신뢰 가능" 스토리.

### 방향 ④ 다관절·임상 지표 확장 (범위 확대)
- **기여**: 무릎 단일 → 고관절/발목/다관절, 그리고 **임상 종단점**(스쿼트 깊이 분류, ROM, 좌우 비대칭) 검증.
- **필요 데이터**: 기존 GT에 다관절 있음(REHAB 26관절 등) → 가능. 임상 라벨/전문가 평가는 추가 필요.
- **리스크**: 범위만 넓히면 "양은 늘되 신규성은 그대로". ①/③와 묶어야 의미.

### 방향 ⑤ 시퀀스 모델(temporal transformer) 보정 (방법 교체)
- 트리→시계열 딥모델. 다만 데이터 양에서 트리가 강할 수 있고, 신규성 대비 위험. **후순위.**

## 4. 추천 경로 (primary + fallback)

**메인 스토리(트랙 A, Q1 응용지) =**
> "현장 배포를 위한 **타깃-프리 robust 단안 무릎각 보정**: 통제 시점 실험으로 전이 실패를 *예측*하고, 자기지도 test-time adaptation으로 *미지 도메인에 GT 없이* 일반화하며, 불확실성으로 신뢰성을 보장한다."

= 방향 **① (핵심) + ② (설명·통제실험) + ③ (신뢰성·신규성)** 의 결합.
④는 여유 있으면 임상 검증 섹션으로, ⑤는 제외.

**Fallback 게이트**:
- ① zero-shot이 naive를 못 이김 → **few-shot 적응**(타깃 소량)으로 전환(여전히 Q1 가능).
- 도메인 추가 확보 실패 → ②(메커니즘)+③(불확실성) 중심의 **통제실험 논문**으로 축소(상위 borderline, but 가능).

## 5. 필요 데이터 (가장 큰 제약 — 우선순위 1)

### 5.1 보유(즉시 사용)
- AIHub(8캠), SUMediPose(6캠, Vicon), REHAB(2캠), FiT3D(4캠). **통제 viewpoint는 충분, 도메인 다양성은 부족.**

### 5.2 추가 확보 목표: **독립 도메인 8~10개로**
leave-one-dataset-out으로 일반화를 주장하려면 도메인 수가 핵심. 후보(공개 3D + 스쿼트/하체 운동, GT 보유):
- 재조사 대상: Human3.6M(스쿼트 유사 동작 부분), HumanEva, TotalCapture, AIST++(춤이라 주의), CMU Panoptic, MoVi, Fit3D 확장 운동군, OpenCap 공개셋(스마트폰 다중뷰+OpenSim, **매우 적합 가능성**), 3DPW(야외).
- 선별 기준: ① 3D GT, ② 스쿼트/하체 굴곡 포함, ③ 다중 카메라(시점 통제) 가점.
- ⚠️ 이전에 MM-Fit(무GT)·AthletePose3D(스쿼트 부적합) 기각됨 — 같은 실수 반복 금지.

### 5.3 (고가치·고비용) 자체 수집
- 소수(5~10명) × 다중 카메라(거리/높이/각도 의도적 변화) + IMU/마커 GT.
- 장점: **완전 통제 testbed** = 상위 인과주장에 결정적. 단점: 시간·장비·IRB.
- 판단: 공개셋으로 도메인 수가 안 차거나, ②의 통제실험을 결정적으로 만들려면 진행.

## 6. 방법론 신규성 체크 (트랙 A 기준 충분 / B는 부족)

- ① test-time adaptation(GT 없는 자기지도 적응) = 본 도메인에서 신규.
- ③ uncertainty-aware 잔차보정 = 신규성 + 임상가치.
- 물리 제약(분절 길이·관절 한계) 결합 = 보조 신규성.
- ※ 트랙 B(CVPR류)를 노리면 위로도 부족 → 별도 신규 아키텍처/SOTA 비교 필요(권장 안 함).

## 8. 리스크 & 정직 가드

- **도메인 확보 실패가 최대 리스크** → 자체수집 fallback 미리 설계.
- zero-shot 미달 가능 → few-shot fallback로도 Q1 성립.
- 메커니즘은 다인자 → "단일 인과" 다시 주장 금지(기각 이력 준수).
- 상위 CV(트랙 B)는 현 자산으로 무리 → 트랙 A로 고정. 욕심내 B를 노리면 둘 다 놓칠 위험.

---

## 9. 결론 (한 문단)

지금 그대로는 상위가 안 된다. 그러나 **갈 길은 명확**하다: 중급/석사를 먼저 내보내 성과를 확정하고, 그 위에 **(데이터) 도메인 8~10개 확보 → (실험) 통제 viewpoint로 오차를 예측 → (방법) GT 없는 test-time adaptation으로 미지 도메인 zero-shot 일반화 → (신뢰) 불확실성 보장** 을 쌓으면 **Q1 응용지(상위)** 가 현실적이다. 핵심 병목은 방법이 아니라 **도메인 수**이며, 그것부터 푼다.
